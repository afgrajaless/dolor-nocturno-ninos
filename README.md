# Dolor nocturno idiopático de miembros inferiores en niños

Presentación médica basada en literatura de 2025–2026 sobre el dolor nocturno idiopático ("dolores de crecimiento") de miembros inferiores en niños.

- Presentación: https://afgrajaless.github.io/dolor-nocturno-ninos/
- Vista del expositor (guion, señales de cambio y cronómetro): https://afgrajaless.github.io/dolor-nocturno-ninos/expositor.html

Cada diapositiva termina con su lista de referencias; al tocar una se resalta la parte donde se usó y se abre su cita. La lista completa está en estilo Vancouver.
